## 용어

| 용어 | 뜻 | 페이지 |
|---|---|---|
| 개체 (Instance, Individual) | 클래스에 속한 하나하나의 실제 대상. 예: A전자 | 01-2 |
| 관계 / 속성 (Property) | 대상의 특징이나 대상 사이의 연결. 객체 속성과 데이터 속성이 있음 | 01-2 |
| 결정 기록 (Decision Record) | 중요한 설계 선택과 이유·대안을 남긴 문서 | 06-4 |
| 근거 제시 (Grounding) | LLM이 확인된 자료를 바탕으로 답하게 하는 것 | 05-3 |
| 라우터 (Router) | 질문 유형을 판단해 처리 경로(검색 방식·모델)를 고르는 구성 요소 | 06-1 |
| 리터럴 (Literal) | 문자열·숫자·날짜 같은 값 | 02-1 |
| 벡터 RAG | 질문과 뜻이 비슷한 문서 조각을 임베딩으로 찾아 근거로 주는 RAG | 06-1 |
| 빈 노드 (Blank Node) | 이름 없이 다른 노드를 묶는 임시 노드 | 02-1 |
| 속성 경로 (Property Path) | SPARQL에서 여러 단계 관계를 한 번에 적는 문법. 예: `ex:suppliesTo+` | 03-2 |
| 속성 그래프 (Property Graph) | 노드와 관계에 속성을 자유롭게 붙이는 그래프 모델 | 03-1 |
| 시소러스 (Thesaurus) | 상하위어에 동의어·관련어를 더한 용어 체계 | 01-3 |
| 오케스트레이션 (Orchestration) | 여러 모델·검색·도구를 순서대로 엮어 하나의 처리 흐름으로 만드는 것 | 06-4 |
| 역량 질문 (Competency Question) | 온톨로지가 답할 수 있어야 하는 질문. 모델링의 출발점 | 03-4 |
| 온톨로지 (Ontology) | 개념과 관계를 명시적으로 정의한 지식의 설계도 | 01-1 |
| 임베딩 (Embedding) | 글의 의미를 숫자 벡터로 바꾼 것. 의미가 비슷하면 벡터도 가까움 | 06-1 |
| 재현율 (Recall) | 정답 중 시스템이 찾아낸 비율 | 07-1 |
| 정렬 / 매핑 (Alignment) | 서로 다른 온톨로지의 같은 개념을 연결하는 작업 | 04-3 |
| 정밀도 (Precision) | 시스템이 찾은 것 중 맞은 비율 | 07-1 |
| 지식그래프 (Knowledge Graph) | 온톨로지에 따라 실제 사실을 채운 그래프 | 01-1 |
| 지식 기반 에이전트 | 온톨로지·지식그래프를 근거로 여러 단계 업무를 수행하는 AI | 06-2 |
| 추론 (Inference, Reasoning) | 적힌 사실과 규칙에서 새 사실을 이끌어 내는 것 | 02-2 |
| 클래스 (Class) | 같은 성질을 가진 대상들의 묶음. 예: 회사 | 01-2 |
| 택소노미 (Taxonomy) | 상하위 분류만 있는 체계 | 01-3 |
| 하이브리드 RAG | 문서(벡터) 검색과 그래프 검색을 함께 쓰는 RAG | 06-1 |
| 트리플 (Triple) | 주어–관계–목적어로 이루어진 지식의 최소 단위 | 01-1 |
| 트리플스토어 (Triple Store) | RDF 트리플을 저장하고 SPARQL로 질의하는 데이터베이스 | 03-1 |
| 환각 (Hallucination) | LLM이 사실이 아닌 내용을 사실처럼 만드는 현상 | 01-4 |
| Cypher | 그래프DB에서 널리 쓰는 질의 언어 | 03-3 |
| F1 | 정밀도와 재현율의 조화 평균 | 07-1 |
| AI 기본법 | 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」, 2026년 1월 22일 시행 | 06-3 |
| GQL | 국제 표준 그래프 질의 언어 (ISO/IEC 39075) | 03-3 |
| GraphRAG | 지식그래프에서 관계를 따라 근거를 찾아 LLM에 주는 방법 | 05-2 |
| IRI | 전 세계에서 하나뿐인 이름. 웹 주소 형태 | 02-1 |
| MCP (Model Context Protocol) | AI 애플리케이션과 외부 도구·데이터를 잇는 프로토콜 | 05-4 |
| OWL | 풍부한 의미와 추론 규칙을 표현하는 W3C 온톨로지 언어 | 02-2 |
| RAG | 답하기 전에 관련 자료를 검색해 LLM에 주는 방법 | 05-2 |
| RDF | 지식을 트리플로 표현하는 W3C 표준 | 02-1 |
| RDFS | 클래스·속성 계층과 범위를 정의하는 RDF 어휘 | 02-2 |
| SHACL | 데이터가 지켜야 할 모양을 정의하고 검사하는 W3C 표준 | 02-4 |
| SKOS | 용어집·분류 체계를 표현하는 W3C 표준 | 02-3 |
| SPARQL | RDF 그래프를 질의하는 W3C 표준 언어 | 03-2 |
| Turtle | 사람이 읽기 쉬운 RDF 표기법 | 02-1 |
